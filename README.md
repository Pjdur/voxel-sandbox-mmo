# Minecraft-like Voxel Game

This project is a multiplayer version of https://github.com/Pjdur/voxel-sandbox, 
using a Node.js Websocker server.

**Features:**

- Break blocks with LMB (Left-Mouse Button)
- Place blocks with RMB (Right-Mouse Button)
- Move with WASD
- Look around with mouse
- 1-5 to switch block types

Textures drawn by me (Pjdur)
